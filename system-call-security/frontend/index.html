User-Friendly System Call Interface

This project simulates a secure interface for operating system system calls. It adds authentication, role-based access control and detailed logging to every system call request.

What is a System Call?

A system call is a controlled entry point where user programs request services from the operating system kernel, such as file I/O or process management. Securing system calls is critical to prevent unauthorized access and to preserve system integrity.

Secure Authentication

Only authenticated users can request system calls. Different roles have different privileges.

Policy-Based Control

Each system call is checked against a security policy to decide if it should be allowed or blocked.

Detailed Logging

Every attempt is logged with user, role, call name, timestamp, status and reason.
